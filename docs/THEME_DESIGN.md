# Afon Training: theme design brief for CC

Use the **Heather & Marigold** direction for Afon Training, a training provider serving GP practices, hospitals, care homes and the leisure sector. The website should feel clean, distinctive, approachable and professionally credible: a specialist training business, not an NHS website, wellness brand or generic course marketplace.

## Colour and typography

Implement these as reusable theme tokens:

| Token | Colour | Use |
|---|---|---|
| Deep plum | `#3B1F45` | Headings, primary text, navigation and footer |
| Heather | `#8A5A9E` | Supporting accents and decorative details |
| Pale heather | `#E9DDEB` | Selected states and occasional section backgrounds |
| Warm off-white | `#FBF7F2` | Main page background |
| Marigold | `#F2A93B` | Primary calls to action and restrained highlights |
| White | `#FFFFFF` | Forms, course cards and reading surfaces |

- **Headings:** Plus Jakarta Sans, weights 600–700. Confident sentence-case headings, without excessive size or tight spacing.
- **Body and interface:** Inter, weights 400–600. Default body text 17–18px with generous line height.
- **Contrast:** Use deep plum text on marigold buttons, not white. Check all text and interactive-state combinations against WCAG AA; supporting colours are not automatically suitable for small text.

## Layout and visual character

- **Structure:** Generous whitespace, clear hierarchy and a consistent grid. Alternate warm off-white and white, with occasional pale-heather sections.
- **Components:** Subtle borders, restrained shadows and approximately 10–12px corner radii. Avoid oversized pill buttons, excessive floating cards, gradients and decorative blobs.
- **Imagery:** Natural photographs of trainers, working teams and practical learning. Represent all sectors rather than relying on clinical imagery.
- **Brand detail:** Explore a restrained flowing-line motif as an optional identity element. Keep it secondary to content and avoid literal river illustrations.
- **Motion:** Short, unobtrusive hover and focus transitions; respect reduced-motion preferences.

## Interface priorities

- **Primary actions:** “Find a course” and “Bespoke training”.
- **Course cards:** Clearly distinguish title, intended audience, delivery format, date and booking action.
- **Consistency:** Use one shared theme across public pages, booking forms and the learner hub.
- **Accessibility:** Include visible keyboard focus, explicit form labels and states that do not rely on colour alone.

Keep copy warm, direct and practical. Avoid NHS-style branding, unverified accreditation claims and invented testimonials; this is a visual direction, not permission to change existing functionality.
